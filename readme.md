# Homework 3 - STA556

We are going to look specifically at the Student Performance data set. 

If you are reproducing this in GitHub Codespaces, complete the following Python package installs before running the `.qmd` file:

```bash
pip install pandas numpy pyyaml jupyter
```
You will also need to install the Quarto CLI engine by running these commands one by one in the terminal:

'''bash
wget [https://quarto.org/download/latest/quarto-linux-amd64.deb](https://quarto.org/download/latest/quarto-linux-amd64.deb)
sudo dpkg -i quarto-linux-amd64.deb
```
Once the environment is set up you can then run the following:

```bash
quarto render reports/homework3.qmd
```
Happy hunting!
